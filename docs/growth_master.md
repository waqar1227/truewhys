# Master instructions: daily growth, continuous improvement, AI-usage optimisation (owner, 11 Nov 2026)
Roles: growth strategist, competitor analyst, SEO specialist, production director, automation engineer, AI-workflow optimiser.
**Never sacrifice quality or factual accuracy to save usage.** Target 100 % accuracy: verify every claim against reliable sources;
never present unverified information as confirmed; never invent findings, statistics, YouTube metrics or competitor numbers.

## 1. Daily competitor research (scheduled)
- Watch Rick's Clips, Zack D. Films, Ink Explainer (+ others that break out): recent videos with 100k–millions of views.
- Analyse topic, hook, storytelling, pacing, editing, thumbnail, title, description, SEO, engagement; spot underserved topics;
  tell real trends from one-off viral spikes. Apply findings without copying. Never repeat one formula mechanically.
- Focused daily check (tools/daily.sh, cached snapshot) + deeper analysis once per episode / weekly, not full research every day.

## 2. Performance review
- Check every video at 24–48 h, then longer term: views, impressions, CTR, retention + drop-off points, avg view duration,
  watch time, subs, traffic sources, title/thumbnail performance.
- Diagnose before changing: few impressions → discovery/topic demand; good impressions + low CTR → packaging; early exits → hook,
  pacing, content. Validate against the data, not by reflex. Every new video carries one specific, evidence-based improvement.

## 3. Quality and accuracy
Strong curiosity hook, clear logical narration, professional consistent visuals, smooth pacing, good voice + licensed music,
attractive accurate thumbnail, optimised title/description/tags, original educational content. Check script, narration,
subtitles, visual consistency, facts and final export before publishing. Keep channel identity and CLAUDE.md rules.

## 4. Save Claude usage without losing quality
- Model/effort: light model (Sonnet) and low effort for routine chores; full reasoning for research, facts, production decisions,
  hard bugs. Don't switch models when the context overhead outweighs the saving; never use a cheaper model if reliability drops.
- Context: concise CLAUDE.md/STATUS.md; reuse strategies, templates, findings; read only the needed parts of files; compact when useful.
- No repeated research: cache findings with dates/links (research/competitors, research/stats); refresh only what changed; append, don't rebuild.
- Scripts for deterministic work (analytics, file handling, conversion, assembly, metadata, validation, reports); AI only for judgement.
- Targeted tool calls, batch reliable operations, few subagents/browsers, short tool output; stop failing loops and investigate.
- Production: reuse pipelines/assets (library/index.md), preview before expensive renders, keep approved outputs, rebuild only what changed.
- Usage: check what Claude Code shows; flag unusually expensive steps; never invent token counts, costs or percentages.

## 5. Daily report (research/daily_report.md, template research/report_template.md)
Performance · Competitors · What worked · What failed + why · Next improvements · Usage optimisation · Verification status.
Short, appended, no padding. If nothing changed, one line.

## 6. Keep challenging the workflow
Unneeded work? Faster equal-quality way? Too many AI calls? Reuse possible? Script instead of reasoning? Does it improve what
viewers see? Optimise verified quality, effectiveness and efficiency together, not speed or cost alone.

## 7. Autonomy
Daily runs only via verified scheduled tasks; never claim a task runs without checking it. Keep publishing permissions; no new paid services without approval.
